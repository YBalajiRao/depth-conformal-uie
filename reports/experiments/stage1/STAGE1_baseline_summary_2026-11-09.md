## 3. Reading (exploratory; within the evidence above)

1. **The v2 conditioning did not improve on its matched control.** v2 − A1 = +0.033 dB, CI [−0.154, +0.235], d_z = +0.01. v2's gain over A0 (+0.242 dB) is matched by A1's own gain over A0 (+0.209 dB). It reflects the difference between training runs, not the v2 pathway.
2. **The physics pathway (A2) is the only §D candidate effect.** Removing it costs −0.184 dB overall, CI [−0.364, −0.011], and −0.196 dB on LSUI. This is the same size as the A0 → A1 shift (+0.209 dB). One seed therefore cannot separate it from run-to-run variation. Under §D it would go to Stage 2, which has not been run.
3. **L_phys (A3) is provisionally redundant** for PSNR. LSUI is −0.196 dB, CI [−0.398, +0.015], just under the 0.2 dB margin. Because the t̂ fields collapsed (§1), this arm cannot separate "L_phys" from "t̂ conditioning".
4. **The NIG loss (A4) has no detectable effect on restoration** (+0.010 dB overall). It is labelled INCONCLUSIVE only because UIEB's +0.204 dB point estimate exceeds 0.2 dB while its CI includes 0. Its uncertainty map is meaningless (untrained).
5. **No arm changes UIEB.** All are about 22.0 dB on 89 images. The CI half-widths are about ±1.0 dB for absolute values and about ±0.4 dB for paired differences. The roughly 6 dB gap between LSUI and UIEB is unchanged by every component tested.
6. **SSIM differences are all ≤ 0.002, and |d_z| ≤ 0.14 for every comparison.**

**Not claimed:**
- that any component contributes or does not contribute (single seed; no Stage 2);
- generalisation beyond this validation split;
- physical parameter identification (wording: "physics-parameterized conditioning").
